About SmarTalk
Developed by **SeawolfAI**.

How to Use
Set Your API Key: Before you begin, click the Settings icon (⚙️) in the top-right corner to enter your Gemini API key. This key is stored securely in your browser's local storage and is required for the translation features to work.
Select Languages:
Choose your source language from the left dropdown. Select "Auto-detect" to have the app automatically identify the language you're typing or speaking.
Choose your target language from the right dropdown.
Translate Text:
Type or paste the text you want to translate into the left-hand text box.
Click the Translate arrow button (→) in the center.
The translation will appear in the right-hand box.
Translate Speech:
Click the Microphone icon (🎙️) to start recording your voice.
Click the Pause icon (❚❚) to stop recording. The transcribed text will appear in the source box.
Click the Translate arrow button (→) to see the translation.
Listen to Translation:
After a translation is complete, click the Play icon (▶) to listen to the translated text spoken aloud.
Features
Text & Speech Translation: Seamlessly switch between typing and speaking.
Auto Language Detection: Let the AI figure out the source language for you.
Text-to-Speech: Hear translations in a natural-sounding voice.
Secure API Key Storage: Your Gemini API key never leaves your browser.
